# Fund My Mac 💻🚀

> **Turn our MacBook Pro 16″ into an advertising canvas for startups.** Sponsor a sticker spot and get your brand seen at tech summits, demo days, and VC meetings worldwide while backing VESPER.

---

## 🌟 Overview

**Fund My Mac** is an interactive, real-time crowdfunding & sticker spot sponsorship platform. Sponsors can claim prime sticker real estate on the MacBook Pro 16″ exterior lid, palm rests, charger, and magic mouse.

- **Live 3D & Interactive Visualizer**: Visual representation of sticker spots across all MacBook surfaces.
- **Realtime Backing**: Instant status and live bidder feed powered by Supabase Realtime.
- **Tiered Sponsorships**: From indie spots to marquee title partnership packages.

---

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **3D / FX:** [Three.js](https://threejs.org/) & [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Realtime / DB:** [Supabase](https://supabase.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Narayaaana11/fundmymac.git
   cd fundmymac
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Add your Supabase credentials:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
